    How to use it
    
      
    
    
    
    
      
    
        
    Typing
    
        
    Type on your own keyboard, or click the keys on the 3D model. Clicking SHIFT, C= or CTRL latches them for the next key.
    
        
    
          
    EscRUN/STOP
    
          
    PageUpRUN/STOP + RESTORE (warm reset)
    
          
    Alt / ⌥C= (Commodore) key
    
          
    Ctrl / TabCTRL
    
          
    Home · Shift+HomeHOME · CLR
    
          
    Backspace · InsertDEL · INST
    
          
    Shift + Altswitch upper/lower case set
    
          
    Ctrl/Alt + 1-8text colours
    
          
    Ctrl + 9 / 0reverse on / off
    
          
    Shift + letterPETSCII graphics
    
          
    F1–F8function keys
    
          
    F9flat 2D screen
